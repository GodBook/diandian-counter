增加 GitHub 在线更新，计数和日志继续保存在本机。

- 设置中新增“检查更新”和 GitHub 版本入口。
- 支持启动时检查新版本（每天最多一次，可关闭）。
- 确认后在应用内下载 APK，显示进度并支持取消。
- 安装前校验文件大小、SHA-256、包名、版本号及应用签名。
- 首次更新可引导开启“允许此来源安装应用”，返回后继续安装。
- 记录版本检查、下载、取消、校验和安装请求。

已安装 1.0.0 的用户需先手动下载本版本并覆盖安装一次，之后即可在应用内更新。请勿先卸载旧版；覆盖安装会保留计数和操作记录。

Android 8.0 及以上可用。更新需要网络能访问 GitHub；无法连接时，离线计数和日志照常可用。
