支持应用内检查、下载和安装 GitHub 更新，并修复 Android 9/10 的签名读取兼容性。

- 设置中检查更新；启动时每天最多自动检查一次，可关闭。
- 显示版本说明、下载进度，支持取消和重新下载。
- 安装前校验大小、SHA-256、包名、版本号及签名。
- 修复 Android 9/10 读取 APK 签名时误判合法安装包的问题。
- 首次安装更新时引导授权，返回后继续安装。
- 覆盖安装保留计数和完整操作记录。

已安装 1.0.0，或在 Android 9/10 上使用 1.1.0 的用户，请先手动下载本版本并覆盖安装一次。不要先卸载旧版。

Android 8.0 及以上可用。联网仅用于检查版本和下载更新，不上传计数或日志；网络需要能访问 GitHub。
